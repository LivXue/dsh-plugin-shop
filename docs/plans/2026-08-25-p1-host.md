# P1 Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `packages/dsh-plugin-store/src/host/` — the `StoreGateway`, an out-of-tree dsh bundle registering the `store/*` Remote (`catalog`, `install`, `installStatus`, `setEnabled`, `outdated`) — such that the real-installation test of spec §11.3.3 passes.

**Architecture:** One npm package `dsh-plugin-store` in `packages/dsh-plugin-store/`, added to the repo's pnpm workspace. It follows the dsh in-box host pattern: a Cordis `TypertRemoteService` with `@Remote`-decorated methods, discovered by `dsh-typert-loader` through a generated `./typert` export and addressed by the client through a generated `./remote` export. Inside the package, the project's own rule applies: a pure core (`catalog.ts`, `install.ts`, `profile.ts`'s pure parts) that policy lives in, and an impure shell (`executor.ts`, the gateway class) that touches the network, the filesystem, and subprocesses.

**Tech Stack:** TypeScript (ESM, `strict`, `noUncheckedIndexedAccess`), zod 4, vitest, tsdown with `@deepseek-ai/dsh-typert-generator`, `@deepseek-ai/cordis` 4.0.1, dsh packages `0.1.1-rc.2`, js-yaml, semver.

**Spec:** [docs/design/2026-08-18-dsh-plugin-store-design.md](../design/2026-08-18-dsh-plugin-store-design.md) — the plan argues from it, so it travels with the plan; executors read both. P1 constraints are also recorded in [2026-08-18-remaining-work.md](2026-08-18-remaining-work.md).

## Global Constraints

- **The Host accepts `{ name, version }`, never an arbitrary spec** (§5.3). The spec it builds itself is exactly `` `${name}@${version}` `` (§7.2), never `^`-prefixed.
- **The Host's cached catalog snapshot is the source of truth** (§5.3): the browser sends a name, the Host decides against its own snapshot and trusts no metadata sent from the browser.
- **Rejection order in `store/install`** (§7.2): not-in-catalog → denied → version-mismatch → needs-acknowledgement. Acknowledgment rule: `tier !== 'verified' && !acknowledged` → `needs-acknowledgement` (so `verified-stale` requires it).
- **Installation shells out to `dsh plugin --profile <p> add <spec>`** (§7.2). Never reimplement the reconcile loop — it lives in `runPlugin` in `apps/cli/src/plugin.ts` and is exported from no package. The store spawns the `dsh` executable; `dsh` inherits the store's pipe via `stdio: 'inherit'`, so streaming logs come for free.
- **Progress is polled, never pushed** (§7.2): `store/install` returns `{ installId }` immediately; the client polls `store/installStatus`. `API_REMOTE_FORWARDED_EVENTS` is a hardcoded in-repository array, so an out-of-tree plugin cannot push events.
- **Per-profile mutex** (§7.2): installs into one profile serialize; the later caller waits.
- **Never roll back automatically** (§7.2, §10): after a pnpm failure, surface stderr verbatim plus the hint `` dsh plugin --profile <p> install ``.
- **The store never writes `allowBuilds`** (§7.2). pnpm ≥10's build-script blocking is a security property obtained for free.
- **Catalog `schemaVersion` higher than 2 is refused loudly** (§10). Never silently degraded. `schemaVersion` 2 is the version this build supports.
- **Catalog unreachable → serve the last cached snapshot with `stale: true`** (§10). Degrade and stay usable. With no cache at all and the network down, throw — there is nothing honest to serve.
- **Install requires a restart** (§8): `installStatus` reports `needsRestart: true` on `done`. v0 ships no restart endpoint.
- **`builtAt` appears only in `index.json`** (§6.2). The Host never embeds it in anything content-addressed.
- **Pure core, impure shell** (CLAUDE.md): policy in pure modules driven by fixtures; `executor.ts` (subprocesses) and the gateway wiring (clock, fs, env) are the shell. A policy decision that migrates into the shell becomes untestable.
- **ESM everywhere; `.ts` extensions in local relative imports; files end with exactly one trailing newline; `strict` and `noUncheckedIndexedAccess` on** (CLAUDE.md conventions).
- **Tests describe behavior.** Four rejection paths tested through the executor by calling `store/install` directly (spec §11.3.2), never by asserting a UI disabled a button.
- **Version pins**: all `@deepseek-ai/*` deps `^0.1.1-rc.2`; `@deepseek-ai/cordis` `^4.0.1`; `zod` `^4.4.3`; `js-yaml` `^4.2.0`; `semver` `^7.6.3`; `tsdown` `^0.22.2`; dev `typescript ^5.6.3`, `vitest ^2.1.4`.

**Key facts this task locks in:**

1. **Layout — the typert generator hardcodes `packages/`.** `WorkspaceAnalyzer.loadRegistrations` (in `@deepseek-ai/dsh-typert-generator`) skips every project reference whose real path is not inside `<workspace-root>/packages/`, and the workspace root is the nearest ancestor of the bundle output containing `tsconfig.host.json`. The package therefore lives at `packages/dsh-plugin-store/`, and the repo root carries `tsconfig.host.json` + `tsconfig.client.json` (TypeScript project-reference aggregate configs; the host one references this package, the client one has an empty `references` array — the store has no client half in P1). This is a layout amendment to spec §5.1, recorded there in the same change.

2. **Dependency identity.** `TypertRemoteService` extends Cordis `Service`; the gateway class is registered with the app's own `@deepseek-ai/cordis` copy. If pnpm installs a *second* cordis copy into the profile tree, `instanceof` checks across the copies can break registration. Host-provided packages must therefore be **optional peerDependencies** — pnpm never auto-installs optional peers, so imports resolve through the app's flat module fallback (`$DSH_HOME/profiles/node_modules`) to the app's own copies. Leaf deps without identity coupling (zod, js-yaml, semver) are ordinary dependencies. This mirrors the in-box pattern: `@deepseek-ai/dsh-host-plugin-inventory` lists cordis as a peer, not a dep.

3. **Build: `tsc` for types, `tsdown` (with the typert plugin) for js + faces.** The generator's tsdown plugin emits `lib/typert.host.js` / `lib/typert.remote-client.js` at the package output root in its `writeBundle`, and lowers decorator syntax before bundling — without it, `@Remote` source does not bundle. `tsc` emits declarations to `lib/types` (the dsh layout).

### Task 3: Catalog core — fetch, verify, cache, stale

**Files:**
- Create: `packages/dsh-plugin-store/src/host/catalog.ts`, `packages/dsh-plugin-store/tests/host/catalog.test.ts`

**Interfaces:**
- Consumes: nothing from earlier tasks beyond the package skeleton.
- Produces:
  - `export const SUPPORTED_SCHEMA_VERSION = 2`
  - `export interface CatalogSnapshot { schemaVersion: number; builtAt: string; entries: Entry[]; denied: DeniedEntry[] }` with `Entry`/`DeniedEntry` as defined here (shape from spec §6.2: `Entry = { name, version, integrity, publishedAt, repository, license, tier, metadata, review?, catalog? }`, `catalog = { category, summary: { en, zh? }, capabilities }`; `DeniedEntry = { name, detail }`). These types live in this module's own `types.ts` — see Task 4.
  - `export interface CatalogResult { snapshot: CatalogSnapshot; stale: boolean }`
  - `export async function loadCatalog(options: { baseUrl: string; cacheDir: string; refresh?: boolean; fetchImpl?: typeof fetch; now?: () => Date; fsImpl?: CatalogFs; sleep?: (ms: number) => Promise<void> }): Promise<CatalogResult>` — fetch the pointer (`<baseUrl>/index.json`), verify the data file's sha256 against the pointer, cache both on disk, serve cache with `stale: true` on network failure; throw when schemaVersion > `SUPPORTED_SCHEMA_VERSION`; throw when the sha256 check fails; throw when offline with no cache.
  - `export interface CatalogFs { exists(p: string): boolean; read(p: string): string; write(p: string, data: string): void }` (fs injection for tests; default wraps `node:fs`).

Behavior spec (from spec §7.1, §10, and the P1 handover constraints):
- Freshness: when the cached pointer is younger than 5 minutes and `refresh` is not set, serve cache without touching the network (`stale: false`).
- `refresh: true` always refetches the pointer. On success the cache is rewritten.
- Any network failure (`fetchImpl` throwing or non-2xx) falls back to cache with `stale: true`; with no cache, rethrow.
- The data fetch uses the URL inside the pointer (`plugins.url`), resolved against `baseUrl`. The sha256 of the data file bytes must equal the pointer's `sha256`; a mismatch throws (`catalog data failed integrity check`), never served.
- `schemaVersion` is checked on both the pointer and the data file; higher than 2 throws (`catalog schemaVersion N is newer than this build supports (2)`).
- The entries and denied lists are validated with zod (untrusted transport input reaching published artifacts); a parse failure throws — fail loud, never silently degrade.
- Cache layout: `<cacheDir>/index.json` and `<cacheDir>/<plugins.<sha>.json>` (the pointer's url basename). Writes are to the cache dir only.

```ts
import { describe, expect, it } from 'vitest'
import { createHash } from 'node:crypto'
import { loadCatalog, SUPPORTED_SCHEMA_VERSION, type CatalogFs } from '../../src/host/catalog.ts'

function dataJson(plugins: unknown[] = [], denied: unknown[] = []): string {
  return JSON.stringify({ schemaVersion: 2, plugins, denied })
}

function pointerFor(data: string, builtAt: string): { pointer: string; url: string; sha: string } {
  const sha = createHash('sha256').update(data).digest('hex')
  const url = `plugins.${sha}.json`
  return {
    pointer: JSON.stringify({ schemaVersion: 2, builtAt, count: 0, plugins: { url, sha256: sha } }),
    url,
    sha,
  }
}

function memFs(): CatalogFs & { files: Map<string, string> } {
  const files = new Map<string, string>()
  return {
    files,
    exists: p => files.has(p),
    read: p => files.get(p) ?? '',
    write: (p, data) => { files.set(p, data) },
  }
}
```

```ts
/** Catalog fetch, verification, and disk cache — the Host's only network path. */

import { createHash } from 'node:crypto'
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { basename, join } from 'node:path'
import { z } from 'zod'
import type { CatalogEntry, DeniedEntry } from './types.ts'

/** Highest schemaVersion this build understands; a higher one is refused (§10). */
export const SUPPORTED_SCHEMA_VERSION = 2

const FRESH_MS = 5 * 60 * 1000
const META_FILE = 'index.meta.json'

const entrySchema = z.object({
  name: z.string(),
  version: z.string(),
  integrity: z.string().nullable(),
  publishedAt: z.string().nullable(),
  repository: z.string().nullable(),
  license: z.string().nullable(),
  tier: z.enum(['verified', 'verified-stale', 'community']),
  metadata: z.enum(['declared', 'derived']),
  review: z.object({
    reviewedVersion: z.string(),
    reviewer: z.string(),
    reviewCommit: z.string(),
    notes: z.string(),
  }).optional(),
  catalog: z.object({
    category: z.enum(['tool', 'provider', 'ui', 'workflow', 'integration', 'other']),
    summary: z.object({ en: z.string(), zh: z.string().optional() }),
    capabilities: z.array(z.string()),
  }).optional(),
})

const dataSchema = z.object({
  schemaVersion: z.number(),
  plugins: z.array(entrySchema),
  denied: z.array(z.object({ name: z.string(), detail: z.string() })).default([]),
})

const pointerSchema = z.object({
  schemaVersion: z.number(),
  builtAt: z.string(),
  count: z.number(),
  plugins: z.object({ url: z.string(), sha256: z.string() }),
})

export interface CatalogSnapshot {
  schemaVersion: number
  builtAt: string
  entries: CatalogEntry[]
  denied: DeniedEntry[]
}

export interface CatalogResult { snapshot: CatalogSnapshot; stale: boolean }

export interface CatalogFs {
  exists: (path: string) => boolean
  read: (path: string) => string
  write: (path: string, data: string) => void
}

const nodeFs: CatalogFs = {
  exists: path => existsSync(path),
  read: path => readFileSync(path, 'utf8'),
  write: (path, data) => { mkdirSync(join(path, '..'), { recursive: true }); writeFileSync(path, data) },
}

export interface LoadCatalogOptions {
  baseUrl: string
  cacheDir: string
  refresh?: boolean
  fetchImpl?: typeof fetch
  now?: () => Date
  fsImpl?: CatalogFs
  sleep?: (ms: number) => Promise<void>
}

function resolveDataUrl(baseUrl: string, url: string): string {
  return /^https?:\/\//.test(url) ? url : new URL(url, baseUrl).href
}

/**
 * Load the catalog snapshot: fetch the pointer, verify the data file's sha256
 * against it, cache both on disk, and serve the cached copy with `stale: true`
 * when the network is unavailable (§10). A schemaVersion higher than this
 * build supports, or a data file that fails the hash or shape check, throws —
 * never silently degraded.
 */
export async function loadCatalog(options: LoadCatalogOptions): Promise<CatalogResult> {
  const {
    baseUrl, cacheDir, refresh = false,
    fetchImpl = fetch, now = () => new Date(), fsImpl = nodeFs,
  } = options
  const indexPath = join(cacheDir, 'index.json')
  const metaPath = join(cacheDir, META_FILE)

  const cachedPointer = (): CatalogSnapshot | null => {
    if (!fsImpl.exists(indexPath) || !fsImpl.exists(metaPath)) return null
    try {
      const meta = JSON.parse(fsImpl.read(metaPath)) as { fetchedAt: string }
      const fetchedAt = Date.parse(meta.fetchedAt)
      if (!refresh && now().getTime() - fetchedAt < FRESH_MS) return readCached()
    } catch {
      // A corrupt sidecar means "no usable freshness fact"; fall through to the network.
    }
    return refresh ? null : readCached()
  }

  const readCached = (): CatalogSnapshot | null => {
    try {
      const pointer = pointerSchema.parse(JSON.parse(fsImpl.read(indexPath)))
      if (pointer.schemaVersion > SUPPORTED_SCHEMA_VERSION) throw new Error(
        `catalog schemaVersion ${pointer.schemaVersion} is newer than this build supports (${SUPPORTED_SCHEMA_VERSION})`,
      )
      const dataPath = join(cacheDir, basename(pointer.plugins.url))
      const data = dataSchema.parse(JSON.parse(fsImpl.read(dataPath)))
      return { schemaVersion: pointer.schemaVersion, builtAt: pointer.builtAt, entries: data.plugins, denied: data.denied }
    } catch {
      // Cache unreadable or invalid — treat as absent rather than failing a
      // boot that could instead fetch a fresh catalog.
      return null
    }
  }

  const fresh = cachedPointer()
  if (fresh !== null) return { snapshot: fresh, stale: false }

  let pointerText: string
  let dataText: string
  try {
    const response = await fetchImpl(new URL('index.json', baseUrl).href)
    if (!response.ok) throw new Error(`catalog pointer returned ${response.status}`)
    pointerText = await response.text()
    const pointer = pointerSchema.parse(JSON.parse(pointerText))
    if (pointer.schemaVersion > SUPPORTED_SCHEMA_VERSION) throw new Error(
      `catalog schemaVersion ${pointer.schemaVersion} is newer than this build supports (${SUPPORTED_SCHEMA_VERSION})`,
    )
    const dataResponse = await fetchImpl(resolveDataUrl(baseUrl, pointer.plugins.url))
    if (!dataResponse.ok) throw new Error(`catalog data returned ${dataResponse.status}`)
    dataText = await dataResponse.text()
    const actual = createHash('sha256').update(dataText).digest('hex')
    if (actual !== pointer.plugins.sha256) {
      throw new Error(`catalog data failed integrity check: expected ${pointer.plugins.sha256}, got ${actual}`)
    }
  } catch (error) {
    const cached = readCached()
    if (cached !== null) return { snapshot: cached, stale: true }
    throw error
  }

  const data = dataSchema.parse(JSON.parse(dataText))
  const snapshot: CatalogSnapshot = {
    schemaVersion: pointerSchema.parse(JSON.parse(pointerText)).schemaVersion,
    builtAt: pointerSchema.parse(JSON.parse(pointerText)).builtAt,
    entries: data.plugins,
    denied: data.denied,
  }
  fsImpl.write(indexPath, pointerText)
  fsImpl.write(join(cacheDir, basename(snapshot.entries.length >= 0 ? pointerSchema.parse(JSON.parse(pointerText)).plugins.url : '')), dataText)
  fsImpl.write(metaPath, JSON.stringify({ fetchedAt: now().toISOString() }))
  return { snapshot, stale: false }
}
```

Note for the implementer: the double `pointerSchema.parse` in the success path is clumsy; restructure with a local `pointer` variable kept from the try block (declare `let pointer` outside the try). Keep the code honest, not just passing.

Also note: `snapshot.schemaVersion` should be checked against `SUPPORTED_SCHEMA_VERSION` once — the check above already throws before caching.

```ts
/** StoreGateway: the Host half of dsh-plugin-store (§5.1). */

import type { Context } from '@deepseek-ai/cordis'
import { Remote, TypertRemoteService } from '@deepseek-ai/dsh-typert-protocol'
import { loadCatalog, type LoadCatalogOptions } from './catalog.ts'
import type { CatalogEntry, DeniedEntry } from './types.ts'

/** Test-only injection points; production callers pass nothing. */
export interface StoreGatewayOptions {
  catalogUrl?: string
  cacheDir?: string
  loadCatalog?: (options: LoadCatalogOptions) => ReturnType<typeof loadCatalog>
}

/** One row of the row config the bundle patch (§cordis.patch.yml) supplies. */
interface StoreRowConfig {
  catalogUrl?: unknown
  cacheDir?: unknown
}

/** `store/catalog` result (§7.3), plus the denied list for the install gate's UI. */
export interface StoreCatalogResult {
  schemaVersion: number
  builtAt: string
  stale: boolean
  plugins: CatalogEntry[]
  denied: DeniedEntry[]
}

/** Remote-only service exposing the five store methods of §7.3. */
export class StoreGateway extends TypertRemoteService {
  private readonly options: StoreGatewayOptions

  constructor(ctx: Context, options: StoreGatewayOptions = {}) {
    super(ctx, 'store')
    this.options = options
  }

  private rowConfig(): StoreRowConfig {
    if (this.options.catalogUrl !== undefined && this.options.cacheDir !== undefined) {
      return { catalogUrl: this.options.catalogUrl, cacheDir: this.options.cacheDir }
    }
    const entry = this.ctx.loader?.entries().find(entry => entry.options.name === 'dsh-plugin-store')
    const config = entry?.options.config as StoreRowConfig | undefined
    if (typeof config?.catalogUrl !== 'string' || typeof config?.cacheDir !== 'string') {
      throw new Error('dsh-plugin-store: the store row is missing catalogUrl or cacheDir config')
    }
    return config
  }

  /** Browse the catalog (§7.3): cached snapshot, refreshed on demand. */
  @Remote('catalog')
  async catalog(args: { refresh?: boolean } = {}): Promise<StoreCatalogResult> {
    const { catalogUrl, cacheDir } = this.rowConfig()
    const load = this.options.loadCatalog ?? loadCatalog
    const { snapshot, stale } = await load({ baseUrl: catalogUrl, cacheDir, refresh: args.refresh ?? false })
    return {
      schemaVersion: snapshot.schemaVersion,
      builtAt: snapshot.builtAt,
      stale,
      plugins: snapshot.entries,
      denied: snapshot.denied,
    }
  }
}

export default StoreGateway
```

Validation rules (pure, in this exact order — spec §7.2):
1. `denied` list contains `name` → `{ ok: false, code: 'denied', detail: `dsh-plugin-store: ${name} is denied: ${entry.detail}` }`
2. `entries` contains no entry with that name → `not-in-catalog`, detail naming the name.
3. entry.version !== args.version → `version-mismatch`, detail stating both.
4. `entry.tier !== 'verified' && !args.acknowledged` → `needs-acknowledgement`, detail naming the tier.

Executor behavior (spec §7.2 + §10):
- Spawn `dsh` (default `'dsh'`, overridable) with args `['plugin', '--profile', profile, 'add', spec]`, `stdio: ['ignore', 'pipe', 'pipe']`, cwd inherited.
- Collect stdout+stderr lines into the log (cap 200 lines). `state` is `'running'` until exit.
- Exit 0 → `{ state: 'done', needsRestart: true }`. Non-zero exit → `{ state: 'failed', detail: `pnpm failed in the profile. Run: dsh plugin --profile ${profile} install — ${lastLogLine}` }` with stderr verbatim in `log` (§10: "stderr verbatim plus a recovery hint").
- Spawn error (`ENOENT`) → `{ state: 'failed', detail: 'dsh not found on PATH — install the dsh CLI to manage profile plugins' }` (mirrors the CLI's own 127 handling).
- The per-profile mutex: `startInstall` chains on the profile's previous install promise, so two installs into one profile serialize; installs into different profiles proceed in parallel.

```ts
/** Install gate: the four rejection paths of §7.2, as a pure function. */

import type { CatalogSnapshot } from './catalog.ts'

export type InstallRejectionCode = 'not-in-catalog' | 'denied' | 'version-mismatch' | 'needs-acknowledgement'

export interface InstallArgs { name: string; version: string; acknowledged?: boolean }

export type ValidateResult = { ok: true } | { ok: false; code: InstallRejectionCode; detail: string }

/**
 * Decide whether one install request may proceed, against the Host's own
 * snapshot (§5.3). The browser sends a name; nothing the browser says about
 * the package is trusted.
 */
export function validateInstall(snapshot: CatalogSnapshot, args: InstallArgs): ValidateResult {
  const denied = snapshot.denied.find(d => d.name === args.name)
  if (denied !== undefined) {
    return { ok: false, code: 'denied', detail: `dsh-plugin-store: ${args.name} is denied: ${denied.detail}` }
  }
  const entry = snapshot.entries.find(e => e.name === args.name)
  if (entry === undefined) {
    return { ok: false, code: 'not-in-catalog', detail: `dsh-plugin-store: ${args.name} is not in the catalog` }
  }
  if (entry.version !== args.version) {
    return { ok: false, code: 'version-mismatch', detail: `dsh-plugin-store: ${args.name}@${args.version} is not the cataloged version (${entry.version})` }
  }
  if (entry.tier !== 'verified' && !args.acknowledged) {
    return { ok: false, code: 'needs-acknowledgement', detail: `dsh-plugin-store: ${args.name} is ${entry.tier}-tier and has not been reviewed; acknowledgement is required` }
  }
  return { ok: true }
}
```

```ts
/** Install executor: spawn the dsh CLI, stream its output, serialize per profile. */

import { spawn } from 'node:child_process'
import { randomUUID } from 'node:crypto'

export type InstallState = 'running' | 'done' | 'failed'

export interface InstallStatus {
  state: InstallState
  log: string[]
  needsRestart?: boolean
  detail?: string
}

const MAX_LOG_LINES = 200

interface RunningInstall {
  status: () => InstallStatus
  finished: Promise<InstallStatus>
}

// One in-flight install per profile (§7.2: pnpm locks itself, but its
// concurrent-access errors are unreadable to a user).
const profileQueues = new Map<string, Promise<unknown>>()

function chain<T>(profile: string, task: () => Promise<T>): Promise<T> {
  const previous = profileQueues.get(profile) ?? Promise.resolve()
  const next = previous.then(task, task)
  profileQueues.set(profile, next.catch(() => {}))
  return next
}

/**
 * Run one `dsh plugin --profile <profile> add <spec>` and track it.
 * Never rolls back; a failure surfaces stderr verbatim plus the recovery hint
 * (§10). The store never passes build-script flags: `allowBuilds` stays the
 * user's explicit decision in the CLI (§7.2).
 */
export function startInstall(options: {
  profile: string
  spec: string
  dshBin?: string
}): RunningInstall {
  const { profile, spec, dshBin = 'dsh' } = options
  const installId = randomUUID()
  const log: string[] = []
  let state: InstallState = 'running'
  let detail: string | undefined

  const append = (line: string): void => {
    log.push(line)
    if (log.length > MAX_LOG_LINES) log.shift()
  }

  const finished = chain(profile, () => new Promise<InstallStatus>((resolve) => {
    const child = spawn(dshBin, ['plugin', '--profile', profile, 'add', spec], {
      stdio: ['ignore', 'pipe', 'pipe'],
    })
    let spawned = false
    child.on('spawn', () => { spawned = true })
    child.stdout.on('data', (chunk: Buffer) => { for (const line of chunk.toString().split('\n')) if (line !== '') append(line) })
    child.stderr.on('data', (chunk: Buffer) => { for (const line of chunk.toString().split('\n')) if (line !== '') append(line) })
    child.on('error', (error) => {
      const code = (error as NodeJS.ErrnoException).code
      state = 'failed'
      detail = code === 'ENOENT'
        ? 'dsh not found on PATH — install the dsh CLI to manage profile plugins'
        : `dsh spawn failed: ${error.message}`
      resolve(status())
    })
    child.on('close', (exitCode) => {
      if (state !== 'running') return
      if (exitCode === 0) {
        state = 'done'
      } else {
        state = 'failed'
        detail = `pnpm failed in the profile directory. Run: dsh plugin --profile ${profile} install`
      }
      resolve(status())
    })
  }))

  const status = (): InstallStatus => ({
    state,
    log: [...log],
    ...(state === 'done' ? { needsRestart: true } : {}),
    ...(detail !== undefined ? { detail } : {}),
  })

  return { installId, status, finished }
}
```

```ts
/** Profile directory discovery and user-layer writes (§8: hot enable/disable). */

import { realpathSync, existsSync, readFileSync, renameSync, writeFileSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { loadOptionalPatches } from '@deepseek-ai/dsh-app-boot'
import { dump } from 'js-yaml'

/** One id-targeted user-layer row (§8: the CLI hot-reloads this file). */
export interface UserLayerRow { id: string; disabled: boolean }

interface ProfileShape { dsh?: { profile?: { bundles?: unknown } } }

/**
 * Find the profile directory that owns `startPath` — the store bundle is a
 * dependency installed inside the active profile, so ascending from its own
 * module path to the nearest ancestor holding both the Loader root
 * (`cordis.yml`) and a `dsh.profile.bundles` manifest is filesystem fact,
 * not a guess.
 */
export function discoverProfile(startPath: string): { name: string; dir: string } {
  let dir = realpathSync(startPath)
  for (;;) {
    const parent = dirname(dir)
    if (parent === dir) break
    dir = parent
    if (!existsSync(join(dir, 'cordis.yml'))) continue
    try {
      const manifest = JSON.parse(readFileSync(join(dir, 'package.json'), 'utf8')) as ProfileShape
      if (Array.isArray(manifest.dsh?.profile?.bundles)) {
        return { name: dir.split('/').at(-1) ?? dir, dir }
      }
    } catch {
      // A package.json that cannot be read or parsed is not a profile manifest.
    }
  }
  throw new Error(`dsh-plugin-store: no profile directory found above ${startPath}`)
}

/**
 * Upsert one row of the profile's user layer (`cordis.patch.yml`). Enabling
 * removes the row so the bundle default rules again; disabling writes
 * `{ id, disabled: true }` (§8: the CLI's watchUserPatches applies the change
 * hot through HMR). Existing rows for other ids are preserved verbatim.
 */
export function setUserLayerRow(options: { profileDir: string; row: UserLayerRow }): void {
  const file = join(options.profileDir, 'cordis.patch.yml')
  const rows = loadOptionalPatches('dsh-plugin-store', file) ?? []
  const others = rows.filter(row => row.id !== options.row.id)
  const next = options.row.disabled
    ? [...others, { id: options.row.id, disabled: true }]
    : others
  const tmp = `${file}.tmp`
  writeFileSync(tmp, dump(next, { noRefs: true }))
  renameSync(tmp, file)
}
```

**Interfaces:**
- Consumes: the gateway's snapshot (`lastSnapshot`) and `readProfileManifest` from `@deepseek-ai/dsh-app-boot` (optional peer, same reasoning as Task 7); `semver.lt` from `semver`.

Semantics: for every catalog entry that also appears in the profile manifest's `dependencies`, where the installed range resolves to a version older than the catalog's (compare the *exact installed version string* recorded in the profile's `dependencies[name]` when it is a bare version; when it is a range like `^1.0.0`, compare the range's minimum via `semver.minVersion`), report it. Comparing `minVersion(range)` against the catalog version is the honest reading.

```ts
import { readProfileManifest } from '@deepseek-ai/dsh-app-boot'
import { lt, minVersion } from 'semver'

export interface StoreOutdatedEntry { name: string; installed: string; latest: string }

  /** Installed plugins whose installed version is older than the catalog's (§7.3). */
  @Remote('outdated')
  async outdated(): Promise<StoreOutdatedEntry[]> {
    if (this.lastSnapshot === null) {
      const { catalogUrl, cacheDir } = this.rowConfig()
      const load = this.options.loadCatalog ?? loadCatalog
      const { snapshot } = await load({ baseUrl: catalogUrl, cacheDir })
      this.lastSnapshot = snapshot
    }
    const manifest = readProfileManifest('dsh-plugin-store', this.profileDirResolved())
    const dependencies = manifest.dependencies ?? {}
    const outdated: StoreOutdatedEntry[] = []
    for (const entry of this.lastSnapshot.entries) {
      const installed = dependencies[entry.name]
      if (installed === undefined) continue
      const floor = installed === entry.version ? installed : minVersion(installed)?.version ?? null
      if (floor !== null && lt(floor, entry.version)) {
        outdated.push({ name: entry.name, installed, latest: entry.version })
      }
    }
    return outdated
  }
```
